## Qué no vamos a fingir

| Pieza JRS | Sustituto en este curso |
|---|---|
| Report Builder | Vistas compartidas + export Word/CSV (como M07 del 101, con columnas de cobertura) |
| LQE / consultas cruzadas RM+QM+CCM | Columna *Validated By* + entrar a ETM; no hay un único SQL de ciclo de vida |
| Cuadros ejecutivos corporativos | Panel de instrumentos del **proyecto** (widgets) |
